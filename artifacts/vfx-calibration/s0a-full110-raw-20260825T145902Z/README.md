# W24 S0a fresh-full110 raw capture

This write-once package preserves the completed formal raw capture for the
fresh, independent 110-sample S0a holdout. Unity exited naturally with code 0,
the true PlayMode proxy passed 1/1, and the archived capture contains exactly
110 read-only completed candidates matching the frozen command set.

`operator-fixture/full` is operator-only. Its labels file remains an unreviewed
template and is not human authority. Do not deliver that directory to a blind
reviewer. `capture` is raw sealed recorder evidence; `source-authority` stores
the exact scene, Prefab, Recipe, manifest, contract, controller, profile, and
capture-tool inputs used by the run. `run-evidence` contains the successful
XML/log/runner and the independent verifier sources. `rejected-preflight`
preserves two environmental ENOSPC attempts that ended before test discovery
and before any candidate directory existed.

Projection has intentionally not run because it freezes an exact QA model
version identity, and no such identity was supplied for this full holdout.
Accordingly this package makes no Visual QA, S0a Gate, L3, L4, publication, or
user-signature claim.
