# Samples

The internal MVP's formal samples are deliberately project assets, not
`Samples~` imports: the canonical Recipes are
`Assets/VFX/Recipes/fireball-2d.default.json` and
`Assets/VFX/Recipes/fireball-3d.default.json`; retained Generated Prefabs are
under `Assets/VFX/Generated/`; and the 2D/3D fixed previews are under
`Assets/VFX/Preview/`.

This embedded package has no importable `Samples~` payload. No S1/S2 spike
asset belongs here. Use the repository path
`docs/release/INSTALL_AND_VERIFY.md` for the supported build and preview flow.
