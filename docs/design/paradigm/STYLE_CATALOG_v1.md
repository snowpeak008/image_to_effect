## 1. 风格的定义与"完全独立于内容"的实现机制

### 1.1 风格是什么

风格 = **渲染取向**（rendering orientation）：同一个形态（由元素决定）、同一个结构（由原型决定），用什么"画法"呈现在屏幕上。它回答的是"线条硬不硬、色阶几级、有没有描边、颗粒是不是方的、饱和度多高、光是否分层"，不回答"这是什么、它怎么动"。

### 1.2 独立性的实现机制：三处叠加点，零处结构改动

风格**不进原型结构**（不增删层、不改节拍、不改接口），只在编译期叠加到三处：

| 叠加点 | 机制 | 作用范围 |
|---|---|---|
| **① 材质族：风格子图（style subgraph）** | 每个特效材质的 Shader Graph 主图末端固定挂一个 `StyleStage` 子图插槽，输入 = 元素 / 原型算出的线性 HDR 颜色 + alpha + 法线 / 边距离（可选），输出 = 最终颜色。不同风格 = 不同子图（`Style_Cartoon` / `Style_Pixel` / `Style_None`）。子图内部做量化、色阶、描边、饱和度重映射、边缘锐化 | 全部材质族层（`core/body/edge/trail/ground/decal/flash/shock/beam_column/link/mesh_shell/surface/veil/column/fill/frame`）与粒子族的粒子材质 |
| **② 粒子族与几何族：风格约束参数集（style constraint set）** | 一组对粒子 / 几何"形状与颗粒度"的约束参数，编译期与元素预设合并（风格优先级高于元素，低于 Recipe 显式参数）：粒子基础形替换（圆→方 / 拉伸→短条）、尺寸量化步长、最小尺寸、旋转量化、Trail 宽度阶梯、几何细分上限 / 下限、顶点位移量化 | `emission.* / orbit / debris / trail / mesh_shell / column / cloth` 等 |
| **③ 局部光：风格光约束** | 光强色阶（连续 / 分档）、闪烁模式的量化（连续正弦→阶跃）、颜色饱和度倍率、是否允许阴影 | `light` 层 |

**优先级合并顺序**（与元素目录 §2.1 一致）：原型层默认 ← 元素预设 ← **风格约束参数集** ← Recipe 显式参数 ← 档位截断。风格子图 ① 不在合并链里——它是**材质图结构的一部分**，由 `style.id` 直接决定挂哪个子图；子图的少量可调参数（色阶数、描边宽、像素尺寸）来自 `style.parameters`。

### 1.3 风格资产的形状（供 T2b）

```
StylePreset
├─ id, displayName
├─ material: { styleSubgraph: <Shader Graph 子图引用>, params{ 见各风格 } }
├─ particleConstraints: { shapeMap{ 元素基础形 → 风格基础形 }, sizeStep, minSize, rotationStep, trailWidthSteps, ... }
├─ meshConstraints: { maxSubdivision, minSubdivision, displacementStep, outlineShell: bool, ... }
├─ lightConstraints: { intensitySteps, flickerQuantize: bool, saturationMul, allowShadows: bool }
└─ paletteRemap: { saturationMul, valueCurve, hueShift, hdrClamp }  // 对元素色板的整体重映射
```

### 1.4 风格与元素的交界：谁管什么

| 问题 | 归属 |
|---|---|
| 火焰顶部是撕裂的舌形还是圆润的团 | 元素（形态倾向） |
| 舌形边缘是渐变还是三级色阶硬切 | **风格** |
| 火星往上飘还是往下掉 | 元素（运动倾向） |
| 火星是圆点、拉伸线还是 4×4 方块 | **风格**（粒子约束） |
| 光是橙色 1800 K 闪烁 | 元素（光预设） |
| 闪烁是连续正弦还是 3 档阶跃 | **风格**（光约束） |
| 色板是 (1.0, 0.35, 0.05) | 元素 |
| 饱和度 ×1.3、亮部截断到 3 级 | **风格**（色板重映射） |

## 2. 卡通 `cartoon`

### 2.1 渲染取向定义

**色阶分层（cel shading）+ 描边（outline）+ 锐利阈值 + 高饱和**。形态边界清晰，明暗用 2~4 级硬切色阶而不是连续渐变，每个形体（或形体组）有一圈一致宽度的暗色描边，颜色饱和度高、对比强，HDR 亮部压成一级"高光白"而不是连续过曝。整体读感：手绘动画的赛璐璐分层。

### 2.2 对材质族的具体要求（`Style_Cartoon` 子图）

| 要求 | 实现 | 参数（`style.parameters`） |
|---|---|---|
| **色阶分层** | 对输入线性颜色求亮度（或直接对 alpha / 噪声阈值场），用 `steps` 级 `floor(x*steps)/steps` 量化，再映射回元素色板的 `cool→primary→secondary→hot` 渐变查找表——即"按亮度分档后每档取色板固定一色" | `shadingSteps` int 2~4（默认 3） |
| **锐利阈值** | 元素材质的 smoothstep 阈值宽度乘以 `edgeSharpness`（0 = 元素原宽度，1 = 宽度趋近 0.005 的硬切）；卡通默认 0.85 | `edgeSharpness` float 0~1 |
| **描边** | 3D：法线外扩壳（复制网格、法线方向外推 `outlineWidth`、背面剔除反转、纯色）；2D 与 quad 类材质：SDF 距离 `d` 在 `[0, outlineWidth]` 区间输出描边色；粒子材质：粒子 quad 内 SDF 圆 / 形的外圈描边 | `outlineWidth` float 0~0.1（世界单位 / UV 单位由层类型决定）；`outlineColor` = 元素 `cool` 色乘 0.4（默认）或显式 |
| **高饱和** | 色板重映射 `saturationMul` 1.2~1.5，`valueCurve` 提亮中间调 | `saturationMul` float（默认 1.3） |
| **HDR 处理** | 亮部 `> hdrClamp` 的区域统一输出 `hot` 色或纯白"高光块"，不做连续过曝渐变 | `hdrClamp` float（默认 1.5） |
| **噪声细节抑制** | 元素材质的细节噪声层权重乘 `detailMul`（卡通默认 0.5：形态由大噪声决定、细节少而干净） | `detailMul` float 0~1 |
| **内描线（可选）** | 在色阶跳变处加一条细暗线（阈值边的二阶导近似），增强"勾线"感 | `innerLine` bool（默认 false） |

### 2.3 对粒子族的风格约束

| 约束 | 值 |
|---|---|
| 基础形替换 | 拉伸 billboard → 保留但长宽比上限 3:1；圆点 → 带描边的圆 / 多角星 SDF；网格粒子 → 低多边形 + 描边壳 |
| 尺寸 | `minSize` 提高（卡通粒子不做"尘"级细颗粒），`sizeStep` 3 档（大 / 中 / 小） |
| 颜色 | 粒子 Color over Lifetime 用 Fixed 模式（阶跃 2~3 色），不用 Blend |
| 数量 | 建议密度倍率 0.6（少而大的粒子比多而细更"卡通"）；这是建议不是硬约束，由 Recipe 决定 |
| 旋转 | 不量化 |
| Trail | 宽度曲线取 3 段阶梯；末端硬截断而非渐细 |

### 2.4 对几何族的风格约束

| 约束 | 值 |
|---|---|
| 细分 | `maxSubdivision` 中档（低多边形读感更卡通），顶点位移保留但**幅度量化 3 档** |
| 描边壳 | `outlineShell: true` → 所有 `mesh_shell / core / column / debris` 网格生成法线外扩描边壳（3D）；成本：每个网格层 +1 draw call，档位 ML/MM 用"边缘光替代描边"（材质菲涅尔暗边） |
| 破碎 | 碎块保留硬边，断面 `edge.fracture` 取纯色（不做断面纹理） |
| 布料 | 顶点位移波频率降低、幅度量化 |

### 2.5 对局部光的风格约束

| 约束 | 值 |
|---|---|
| 强度色阶 | `intensitySteps` 3（光强在 0.33 / 0.66 / 1.0 三档间阶跃，配合材质色阶） |
| 闪烁量化 | `flickerQuantize: true`（元素 `flicker/breathe` 的连续曲线转 3 档阶跃） |
| 饱和度 | 光色 `saturationMul` 1.2 |
| 阴影 | 允许（PM/PH），但建议硬阴影 |

### 2.6 2D / 3D 差异

| 项 | 3D | 2D |
|---|---|---|
| 描边 | 法线外扩壳（网格层）+ SDF 描边（quad / 粒子） | 全部 SDF 描边（Sprite alpha 距离场或形状 SDF）；Sorting 上描边层在本体下一层 |
| 色阶 | 可结合法线·光方向做真正的 cel 明暗（`mesh_shell / debris / column` 等实体几何）；透明体积类仍按亮度量化 | 无法线光照，全部按亮度 / 噪声场量化 |
| 排序 | 描边壳用背面剔除反转，透明队列内需控制 render queue 偏移 | 显式 Sorting Order 偏移（描边 -1） |
| 局部光 | Point / Spot 阶跃强度 | Light2D 阶跃强度 |

### 2.7 已知张力（供 T2b 权衡）

- 透明体积层（`body/fog`）加描边会破坏体积感——卡通风格对 `body.volume` 类层默认关闭描边只保留色阶（`outlineWidth` 对这些层的默认值 0）。
- 描边壳在 ML/MM 档禁用（成本），改用材质菲涅尔暗边近似。

## 3. 像素 `pixel`

### 3.1 渲染取向定义

**Shader 内量化到虚拟像素栅格 + 色阶分级（有限色板）+ 硬边无抗锯齿感 + 粒子 / 几何吸附栅格**。关键：**保持原渲染分辨率**——不是把画面渲到小 RT 再放大，而是在每个特效材质的 shader 内把 UV / 世界坐标吸附到一个虚拟像素栅格（`pixelSize`），使特效自身呈现"由大像素构成"的读感，而场景其它内容（用户的游戏）不受影响。这是用户裁定的自包含方案。

### 3.2 对材质族的具体要求（`Style_Pixel` 子图）

| 要求 | 实现 | 参数 |
|---|---|---|
| **UV 栅格量化** | 材质采样噪声 / SDF 前，把 UV（quad 类）或世界坐标投影（网格类：用屏幕空间 / 物体空间栅格，T2b 定）吸附到 `floor(uv / pixelSize) * pixelSize`；所有噪声、SDF、阈值都在量化后的坐标上计算，因此形态边缘自然呈阶梯像素 | `pixelSize` float（UV 单位或世界单位；默认对应屏幕上约 4~8 像素一格） |
| **色阶分级** | 输出颜色量化到 `colorSteps` 级（每通道或亮度），再映射到元素色板的**离散色带**（色板 5 色即 5 级，不插值） | `colorSteps` int 3~8（默认 5） |
| **无抗锯齿边** | 阈值宽度强制为 0（硬 step），alpha 二值化（`alphaCutoff`），不做半透明渐隐；透明度分级用**有序抖动**（Bayer 4×4 矩阵，在虚拟像素栅格上）模拟 | `alphaCutoff` float（默认 0.5）；`ditherLevels` int 0~4（0 = 不抖动） |
| **时间量化** | 材质动画时间 `floor(time * frameRate) / frameRate`，让流动 / 闪烁按低帧率跳动（像素动画的节奏感）；这不是序列帧——形态仍是程序化算出的，只是采样时间被量化 | `frameRate` float 8~15（默认 12） |
| **HDR 处理** | `hdrClamp` 后亮部取色板 `hot` 单色，不发光扩散（像素风的"发光"靠色带里的亮色） | `hdrClamp`（默认 1.0） |
| **色板重映射** | 饱和度 ×1.1，明度曲线压中间调，生成 5 色离散色带 | `saturationMul` 1.1 |
| **描边（可选）** | 1 虚拟像素宽的暗色描边（SDF 距离量化后 = 1 格） | `outline1px` bool（默认 true） |

**明确不做**：不使用低分辨率 RenderTexture；不使用相机 / 后处理的像素化 pass；不烘任何序列帧。

### 3.3 对粒子族的风格约束

| 约束 | 值 |
|---|---|
| 基础形替换 | 全部粒子基础形 → 方块 quad（SDF 方形 / 十字 / 3×3 图案，程序化）；拉伸 billboard → 短条（长度量化到整格倍数，最长 4 格） |
| 位置吸附 | 粒子位置在渲染前吸附到虚拟栅格（VFX Graph：Output 前 `floor(pos / pixelWorldSize) * pixelWorldSize`；ParticleSystem：材质顶点着色器内吸附中心点） |
| 尺寸 | 量化到 1 / 2 / 3 / 4 格四档；`minSize` = 1 格 |
| 颜色 | Fixed 模式 3~5 色，无 Blend |
| 旋转 | 量化到 90°（方块粒子）或 0 |
| 数量 | 建议密度倍率 0.5（像素风粒子稀疏、每颗清晰） |
| Trail | 宽度量化到 1 / 2 格；顶点位置吸附栅格；末端硬截断 |
| 时间 | 粒子模拟不量化（运动平滑），但渲染位置吸附栅格产生"跳格"感 |

### 3.4 对几何族的风格约束

| 约束 | 值 |
|---|---|
| 细分 | `maxSubdivision` 低（低多边形）；顶点位移量化到栅格 |
| 描边壳 | 3D 用 1 格宽法线外扩壳（可选）；2D 用材质 1px 描边 |
| 破碎 | 碎块数建议减半、块更大；碎块位置吸附栅格 |
| 布料 | 顶点位移量化到栅格、波频率低 |
| 网格材质 | 3D 网格类层的栅格量化用**物体空间**坐标（保证旋转时像素跟随物体而非屏幕，避免"闪烁爬行"）——T2b 需验证与屏幕空间方案的读感差异，见未决问题 |

### 3.5 对局部光的风格约束

| 约束 | 值 |
|---|---|
| 强度色阶 | `intensitySteps` 4 |
| 闪烁量化 | `flickerQuantize: true`，且按 `frameRate` 时间量化 |
| 范围 | 光照范围建议量化（3D 无法真正像素化光照，接受连续光作为妥协；2D Light2D 的 falloff 无法量化，同样接受） |
| 阴影 | 不允许（`allowShadows: false`）——软阴影与像素风冲突 |

### 3.6 2D / 3D 差异

| 项 | 3D | 2D |
|---|---|---|
| 栅格空间 | 网格层：物体空间栅格（默认）或屏幕空间栅格（可选参数 `gridSpace`）；quad / billboard 层：UV 栅格 | 全部 UV 栅格或世界 XY 栅格（正交相机下两者等价，推荐世界 XY 使多层特效栅格对齐） |
| 栅格对齐 | 不同层的栅格难以完全对齐（透视），接受 | 世界 XY 栅格 + 相同 `pixelWorldSize` → 所有层栅格天然对齐，是像素风的最佳维度 |
| 光 | 连续 Point Light（妥协） | 连续 Light2D（妥协）；可用 `ground.cast` 材质层做量化的"假光斑"替代 |
| 排序 | 透明队列 | Sorting Layer；抖动透明与 Sorting 无冲突 |

### 3.7 已知张力

- 3D 透视下的栅格量化必然与屏幕像素不对齐（除非用屏幕空间栅格，但那会在物体移动时"爬行"）；像素风在 3D 的读感是"体素感 / 方块感"而非严格像素画。这是维度差异，接受。
- 局部光无法量化——接受连续光，靠材质色阶承担像素感。
- 有序抖动在 ML 档可能过重（overdraw + 视觉噪），ML 档默认 `ditherLevels` 0。

## 4. 后续候选风格（仅一行定义，不展开）

| id | 一行定义 | 主要机制预判 |
|---|---|---|
| `realistic` 写实 | 连续渐变、物理合理的发光与体积、细节噪声全开、软阴影 | `Style_None` 子图 + 细节层权重 1.0 + 允许阴影；本质是"无风格叠加"的基线 |
| `stylized` 风格化 | 介于写实与卡通之间：柔化色阶（4~6 级 + 软过渡）、无描边、饱和略高、形态夸张倍率 | 软量化 + 形态幅度倍率 |
| `inkwash` 水墨 | 低饱和 / 单色、边缘渗化（阈值边模糊 + 飞白噪声）、留白、笔触方向性 | 去饱和 + 边缘扩散噪声 + 方向性拉伸 |
| `neon` 霓虹 | 细亮线 + 宽柔晕、暗底、高饱和互补色、边缘发光为主体 | 双阈值（线 + 晕）+ 色板转互补高饱和 |
| `holo` 全息 | 扫描线 + 色散边（RGB 偏移）+ 半透 + 故障闪 | 扫描线叠加 + 通道偏移 + 低概率 UV 错位 |
| `dark` 暗黑 | 低明度、高对比、去饱和偏冷、粗糙颗粒噪声、边缘破碎 | 色板压暗 + 颗粒噪声叠加 + 阈值破碎 |

## 5. 风格与档位的交互

| 风格约束 | 与档位的关系 |
|---|---|
| 卡通描边壳（3D） | ML/MM 禁用（用材质暗边替代）；MH+ 启用 |
| 像素抖动透明 | ML 关（`ditherLevels` 0）；MM+ 2 级；PM+ 4 级 |
| 像素时间量化 | 与档位无关（它降低视觉刷新率但不降低成本） |
| 色阶量化 | 与档位无关（shader 内 1~2 条指令） |
| 粒子密度建议倍率 | 风格建议（0.5~0.6）与档位上限**取小** |
