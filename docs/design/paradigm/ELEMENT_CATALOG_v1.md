## 1. 元素的定义与它解决什么问题

ADR-010 §2 把内容轴拆为**原型 × 元素**：原型给结构，元素给物理属性。同一个投射物原型，火元素与水元素在层结构上完全一致，但形态差异巨大——这种差异不是"换个颜色"能表达的，它体现在：

- **运动倾向**：粒子往哪飘、拖尾怎么断、碎屑如何落地。
- **形态倾向**：核心是圆润的团、锐利的簇、分叉的弧、还是流动的膜。
- **边缘性格**：柔和渐隐、硬阈值、锯齿、液态张力。
- **能量性格**：是否发光、发光色温、闪烁节律、是否留残迹。

因此元素是一组**预设倾向**（preset tendencies），按 5 个技术族各自给出，再通过原型的层角色（`core/body/edge/trail/emission/...`）自动注入。元素不修改原型的层结构、节拍与接口——只修改每一层的"长相和动法"。

### 1.1 元素画像的固定结构

每个元素一节，固定七段：

1. **物理画像**：运动倾向 / 形态倾向 / 边缘性格 / 能量性格 / 重力感 / 残留倾向，各一短语。
2. **色板**（3~5 色，HDR 友好）：`primary`（主体）/ `secondary`（次体）/ `hot`（最亮核，HDR > 1）/ `cool`（外缘暗部）/ `residue`（残迹）。色值为线性空间 RGB（0~N，N 可大于 1 表示 HDR 强度），风格层可整体重映射。
3. **材质族预设**（Shader Graph）：噪声形态 / 层数与速度比 / 阈值性格 / 边缘处理 / 流动方向 / 顶点位移倾向 / 发光。
4. **GPU 粒子族预设**（VFX Graph）：主力场（上升 / 重力 / 湍流 / 吸引 / 轨道…）/ 粒子基础形（拉伸 billboard / quad / 网格）/ 寿命与尺寸曲线性格 / 碰撞行为 / 事件分裂。
5. **CPU 粒子族预设**（ParticleSystem）：把 GPU 预设翻译成 ParticleSystem 模块组合（Velocity / Force / Noise / Color / Size / Collision / Trails / Sub Emitters）。
6. **几何族预设**：基础几何族（球 / 簇 / 锥 / 环 / 螺旋 / 块 / 膜）、顶点位移倾向、程序化生成器选择（供 `mesh_shell / debris / column / link / core` 等层用）、破碎风格。
7. **局部光预设**：色温 / 强度倍率 / 闪烁模式（`steady/breathe/flicker/pulse/strobe`）/ 衰减性格。

随后是 **层角色注入表**：本元素对各层角色最显著的改写（只列显著项）与 **2D / 3D 变体差异**。

### 1.2 元素强度轴（elementIntensity）

每个元素预设内含一条 0~1 的**元素强度**（`elementIntensity`，Recipe v2 顶层 `element.intensity`）：0 = 该元素性格最收敛（接近"无元素"的中性物理），1 = 最夸张（形态倾向、运动倾向、发光全部推到极致）。它不是标准参数 `intensity`（那是亮度 / 发射率倍率），而是"元素味道"的浓度。

## 2. 对接机制："元素预设一次做好，所有原型自动获得"

### 2.1 三层注入

```
原型（结构）           元素预设（倾向）                    风格（渲染取向）
layer.role = core  ──▶ element.material.core.*  ──▶  style.material.*（量化/描边/色阶）
layer.role = emission ▶ element.particles.emission.*
layer.role = light ───▶ element.light.*
```

1. **原型层声明角色**（`role`，取自 `PROTOTYPE_CATALOG_v1.md` §2.1 词表）与技术族（`technique.family`）。
2. **元素预设按 (角色, 技术族) 索引**提供一组参数默认值与一组"变体选择"（如材质子图选 `noise_flame_billow` 还是 `noise_crystal_facet`）。角色支持后缀通配：`emission.*` 的预设适用于 `emission.sparks` / `emission.debris` 等，除非有更具体的键。
3. **编译期合并顺序**：原型层默认值 ← 元素预设 (role, family) ← 元素预设 (role.suffix, family) ← Recipe 层显式 `parameters` ← 风格叠加（只作用于材质族的量化 / 描边 / 色阶通道与粒子族的形状 / 颗粒度约束）← 档位截断。后者覆盖前者。

### 2.2 元素预设资产的形状（供 T2b 实现）

每个元素是一个 **ElementPreset** 资产（ScriptableObject 或 JSON 编译到 ScriptableObject），结构：

```
ElementPreset
├─ id, displayName, palette{primary, secondary, hot, cool, residue}
├─ physics{ motion, form, edge, energy, gravitySense, residue }   // 文字标签 + 数值倾向
├─ material:   map<roleGlob, { subgraphVariant, params{...} }>
├─ gpuParticles: map<roleGlob, { graphVariant, params{...} }>
├─ cpuParticles: map<roleGlob, { moduleRecipe, params{...} }>
├─ mesh:       map<roleGlob, { generatorVariant, params{...} }>
└─ light:      map<roleGlob, { colorTemperature, intensityMul, flickerMode, flickerRate, flickerDepth, decayShape }>
```

`roleGlob` 例：`core`、`emission.*`、`emission.smoke`、`*`（兜底）。T2b 决定具体序列化格式与 Shader Graph 子图 / VFX Graph 模板的变体命名规范；本文档只给每个元素在每族的**倾向与变体语义**。

### 2.3 元素与"无元素 / 纯物理"的关系

`element: none` 时编译器只使用**物理子画像**（§4）——它们同样是 ElementPreset，只是没有发光、色板取自源材质或中性灰、局部光全关。物理破坏类（D 类）原型默认 `element: none`，只有"由元素引起的破坏"时才注入元素（此时元素预设只作用于 `edge.fracture / emission.chips / flash / light` 等"元素敏感度"标注的层，`debris` 主体仍保持物理画像）。

### 2.4 多元素

Recipe v2 允许一个原型的**单个层**覆写元素（`layer.elementOverride`），用于双元素组合（如核心是一种元素、尾迹是另一种）。编排级允许每个子实例不同元素。v1 不做元素"混合插值"，只做按层选择。

## 3. 元素目录（13 个）

### 3.1 火 `fire`

**物理画像**

| 维度 | 倾向 |
|---|---|
| 运动 | 向上、翻腾、加速逃逸；火星抛物后飘升 |
| 形态 | 圆润舌形团，上部撕裂成舌尖；无硬边 |
| 边缘 | 柔和阈值 + 细碎撕裂；边缘由亮转暗再转透明 |
| 能量 | 强发光，核心 HDR 白黄；闪烁快而不规则 |
| 重力感 | 负（浮力主导） |
| 残留 | 烟（上升）、焦痕（暗）、余烬（闪烁后熄） |

**色板**：`primary` (1.0, 0.35, 0.05) · `secondary` (1.0, 0.7, 0.15) · `hot` (4.0, 3.2, 1.6) · `cool` (0.35, 0.05, 0.0) · `residue` (0.08, 0.06, 0.05)

**材质族预设**：噪声 = 双层 FBM，大层慢向上滚动、小层快向上滚动（速度比 1:2.3），沿 V 方向拉伸 1.5×；阈值 = 软阈值（smoothstep 宽 0.15）+ 顶部撕裂（阈值随 V 增大）；边缘 = 色阶由 hot→primary→cool 的渐变查找；流动方向 = +Y（局部）；顶点位移 = 顶部顶点随噪声上下抖；发光 = 核心 HDR 强，随 V 衰减。**3D**：球壳法线噪声 + 视线方向二次采样造体积；**2D**：单 quad 平面噪声，V 拉伸更强（2×）。

**GPU 粒子族预设**：主力场 = 向上浮力 + 中等湍流（Curl 噪声频率中，强度中）；基础形 = 拉伸 billboard（沿速度）用于火星，quad 用于火团；寿命 = 短（0.3~1.2 s），尺寸 = 起大快缩（火团）或起小恒定（火星）；碰撞 = 触地弹跳后熄；事件 = 火星寿命末尾 10 % 概率分裂为 2 个更小火星。

**CPU 粒子族预设**：Velocity over Lifetime +Y 递增；Force = 小随机上飘；Noise 模块中频中强；Color over Lifetime hot→primary→cool→透明；Size over Lifetime 先 1.2 后 0；Collision 世界平面 + 弹性 0.2 + 寿命损失 0.5；Trails（火星）短寿命。

**几何族预设**：核心基础形 = 球（低多边形）+ 顶点位移"舌形拉伸"；`mesh_shell` 破裂风格 = 烧穿（阈值边缘）而非块状；`link` 风格 = 波浪带（振幅小频率高）；`column` = 上宽下窄锥柱翻腾；`debris` 无（火不产块，交给物理子画像"余烬 / 焦炭块"）。

**局部光预设**：色温 1800~2400 K（橙）；强度倍率 1.3；模式 `flicker`（速率 8~14 Hz，深度 0.25）；衰减 = 指数。

**层角色注入表（显著项）**

| 角色 | 火的改写 |
|---|---|
| `core` | 舌形团 + 顶部撕裂，HDR 白核 |
| `body` | 上升翻腾体积，比核心大 40 % 且更暗 |
| `trail` | 连续但顶部撕裂的舌带；带上叠加火星 |
| `emission.*` | 上飘火星（拉伸 billboard）为主，落地熄；`emission.smoke` 强制开启为灰黑上升大粒子 |
| `edge` | 暗红外缘 + 热扭曲感（用 UV 微扰代替屏幕扭曲） |
| `decal` | 焦痕：暗、边缘炭化撕裂、中心微亮余烬闪烁 |
| `ground` | 阵纹为舔舐火舌形 |
| `debris` | 不改写块几何，只给断面 `edge.fracture` 加余烬发光 |
| `light` | 橙、闪烁 |

**2D / 3D 差异**：2D 火团用 V 方向拉伸更强的噪声与更高的阈值撕裂补偿缺失体积；2D 火星 Sorting 分前后两组；2D Light2D 用 Point + 轻微 falloff 抖动模拟闪烁。

### 3.2 冰 `ice`

**物理画像**

| 维度 | 倾向 |
|---|---|
| 运动 | 静止、结晶生长（由点向外）、碎裂后直落；寒气下沉 |
| 形态 | 锐利多面体、簇状棱柱、六方对称；硬边 |
| 边缘 | 硬阈值 + 菲涅尔高光；半透明内散射 |
| 能量 | 弱自发光（冷白蓝）；稳定不闪烁 |
| 重力感 | 正（碎晶直落、寒气沉） |
| 残留 | 冻痕（白霜边缘结晶蔓延）、寒气雾（贴地下沉） |

**色板**：`primary` (0.55, 0.85, 1.0) · `secondary` (0.85, 0.95, 1.0) · `hot` (1.6, 2.0, 2.4) · `cool` (0.15, 0.35, 0.6) · `residue` (0.8, 0.9, 0.95)

**材质族预设**：噪声 = Voronoi（晶格）+ 低频 FBM 作内部散射；阈值 = 硬阈值（宽 0.02）+ 结晶生长模式（阈值从种子点沿 Voronoi 单元逐格推进）；边缘 = 菲涅尔高光 + 折射感近似（法线扰动的高光偏移，不用屏幕折射）；流动 = 几乎静止（速度 0.05×），只有内部散射慢漂；顶点位移 = 尖刺沿法线突出；发光 = 弱、均匀。**3D**：多面体网格 + 菲涅尔真实；**2D**：quad 上的 Voronoi 晶格 SDF + 伪菲涅尔（到形状边的距离）。

**GPU 粒子族预设**：主力场 = 重力 + 极低湍流；基础形 = 小多面体网格粒子（碎晶）与拉伸 billboard（冰针）；寿命中（0.8~2 s）；尺寸恒定后瞬消（碎裂感）；碰撞 = 触地滑动、微弹、不消失（短暂停留后阈值消散）；事件 = 碎晶落地分裂为更小晶粒。寒气：大 quad、极慢、贴地下沉、透明度低。

**CPU 粒子族预设**：Gravity Modifier 1.0；Noise 关或极弱；Rotation over Lifetime 慢；Color 恒定后末段硬切；Collision 世界 + 弹性 0.1 + 停留；Render Mode = Mesh（小多面体）。

**几何族预设**：基础形 = 六方棱柱簇 / 尖锥簇（程序化 `crystal_cluster` 生成器：N 根随机长度棱柱从中心向外）；`mesh_shell` 破裂 = 块状 Voronoi 碎裂 + 直落；`link` 风格 = 折线（硬拐点）；`column` = 由地面向上生长的棱柱簇；`mesh_shell.cage` = 棱刺围栏。

**局部光预设**：色温 8000~12000 K（冷白蓝）；强度倍率 0.7；模式 `steady`（可选 `breathe` 速率 0.3 Hz 深度 0.1）；衰减 = 线性。

**层角色注入表（显著项）**

| 角色 | 冰的改写 |
|---|---|
| `core` | 多面晶体（3D 网格 / 2D 晶格 SDF），高光硬边 |
| `body` | 寒气：下沉、贴地、慢 |
| `trail` | 断续冰针 + 悬浮碎晶，不连续 |
| `emission.*` | 碎晶直落（网格粒子），落地停留后消 |
| `edge` | 菲涅尔白蓝高光 |
| `decal` | 冻痕：白霜由中心向外结晶蔓延，边缘六方分叉 |
| `ground` | 阵纹 = 六方对称晶格 |
| `mesh_shell / debris` | 晶簇几何、块状碎裂直落 |
| `light` | 冷白蓝、稳定 |

**2D / 3D 差异**：2D 晶体用 Voronoi SDF 内描高光线模拟棱面；2D 碎晶用 Sprite 网格三角切片 + Rigidbody2D；寒气在 2D 是贴"地面线"的横向 quad。

### 3.3 雷 `lightning`

**物理画像**

| 维度 | 倾向 |
|---|---|
| 运动 | 瞬移式跳跃（不连续位置）、分叉、抽搐；无惯性 |
| 形态 | 锯齿折线、树状分叉、细而亮；核心为白热线 |
| 边缘 | 极硬核 + 宽柔光晕（双阈值） |
| 能量 | 极强瞬发光，白蓝紫；频闪（strobe） |
| 重力感 | 无 |
| 残留 | 电离余辉（极短）、焦点（小黑点）、残余小电弧跳动 |

**色板**：`primary` (0.6, 0.7, 1.0) · `secondary` (0.85, 0.6, 1.0) · `hot` (6.0, 6.0, 8.0) · `cool` (0.2, 0.15, 0.5) · `residue` (0.05, 0.05, 0.08)

**材质族预设**：噪声 = 一维折线噪声（沿 U 采样的 Value 噪声驱动 V 偏移）+ 每帧随机相位跳变（不插值，`floor(time*rate)` 采样）；阈值 = 双阈值：极窄硬核（宽 0.005）+ 宽柔晕（宽 0.3，低亮）；边缘 = 无渐变，硬切；流动 = 不流动，跳变（10~30 Hz）；顶点位移 = 折线顶点抖动；发光 = 核心极强 HDR。**3D**：LineRenderer / 程序化带面向相机 + 分叉子带；**2D**：同（本元素两维几乎一致）。

**GPU 粒子族预设**：主力场 = 无（粒子瞬生瞬灭，位置随机跳）；基础形 = 短拉伸 billboard（小电弧）+ 点；寿命极短（0.05~0.2 s）；尺寸恒定；碰撞无；事件 = 生成时分裂为 2~3 个子弧沿随机方向。

**CPU 粒子族预设**：Emission Bursts 多次短脉冲；Velocity 随机高速极短；Color 恒白蓝硬切；Size 恒定；Trails 关（用 Stretched Billboard）；Sub Emitters（Birth）生成小弧。

**几何族预设**：基础形 = 折线（`jagged_polyline` 生成器：N 段，每段随机偏移，递归分叉 depth 1~3）；`core`（球类原型）= 球 + 表面跳动折线贴附（材质通道）；`mesh_shell` 破裂 = 电离散裂（阈值噪声高频闪后整体消失，无块）；`link` = 分叉折线（本元素的天然形态）；`mesh_shell.cage` = 环形电弧环（跳变）。

**局部光预设**：色温 9000~15000 K（白蓝紫）；强度倍率 2.0；模式 `strobe`（速率 15~30 Hz，深度 0.8）；衰减 = 阶跃（瞬亮瞬灭）。

**层角色注入表（显著项）**

| 角色 | 雷的改写 |
|---|---|
| `core` | 白热球 + 表面跳动电弧线 |
| `body` | 宽柔光晕，随核心频闪 |
| `trail` | 锯齿折线（不连续、跳变、分叉），非丝带 |
| `link.* / beam_column.*` | 分叉折线 / 锯齿柱，跳变 |
| `emission.*` | 瞬生瞬灭小电弧，无重力 |
| `edge` | 硬核 + 宽晕 |
| `decal` | 焦点 + 放射状焦纹（Lichtenberg 图形程序化） |
| `mesh_shell.dissolve` | 电离散裂：高频闪烁后瞬消 |
| `light` | 白蓝、频闪 |

**2D / 3D 差异**：几乎一致；3D 折线在空间中随机偏移，2D 限于平面；2D 的 Light2D 频闪同样用 intensity 阶跃。

### 3.4 水 `water`

**物理画像**

| 维度 | 倾向 |
|---|---|
| 运动 | 流动、抛物飞溅、表面张力聚成珠、落地摊开 |
| 形态 | 圆润液滴、拉伸液柱、薄膜、涟漪；软边 |
| 边缘 | 液态张力边（SDF 平滑并集）+ 高光线 |

| 残留 | 湿迹（暗色、边缘不规则、慢干）、涟漪、水洼 |

**材质族预设**：噪声 = 双层流动 FBM（沿流向拉伸）+ 法线扰动通道（高光偏移）；阈值 = 软阈值 + SDF 平滑并集（`smoothmin`）制造液滴合并；边缘 = 高光线（法线与视线夹角阈值）+ 半透明；流动 = 沿重力 / 流向；顶点位移 = Gerstner / 正弦波（表面）或液滴拉伸（沿速度）；发光 = 无（`emissive` 0），靠高光。**3D**：真实法线扰动高光；**2D**：SDF 边高光线 + 内部流动噪声。

**GPU 粒子族预设**：主力场 = 重力 + 轻微阻力；基础形 = 拉伸 billboard（沿速度，速度越快越长）或球网格（大液滴）；寿命中；尺寸随速度变化（张力形变）；碰撞 = 触地摊开（生成湿迹事件）并消；事件 = 大液滴碰撞分裂为 3~6 小滴。

**CPU 粒子族预设**：Gravity 1.0；Velocity Stretched Billboard 长度倍率 0.3；Color 恒定半透；Size 微增；Collision 世界 + 弹性 0 + 触发 Sub Emitter（Collision → 小溅）。

**几何族预设**：基础形 = 球（高细分）+ 顶点位移"张力抖动"；`core.crown`（飞溅）= 程序化冠 + 柱；`link.stream` = 抛物线管，截面随流速收窄；`surface` = 细分平面 Gerstner；`mesh_shell` 破裂 = 化水（阈值从上向下 + 顶点下垂位移）；`mesh_shell.cage` = 环形水带。

**局部光预设**：无自发光；`light` 层在水元素下默认关闭，除非风格 / recipe 显式开启（如作为反射近似的极弱蓝光，强度倍率 0.2，`steady`）。

**层角色注入表（显著项）**

| 角色 | 水的改写 |
|---|---|
| `core` | 圆润液滴 / 团，高光线，半透 |
| `body` | 雾状水汽（细小、慢） |
| `trail` | 拉伸液带 + 脱落液滴（滴落） |
| `emission.*` | 液滴（沿速度拉伸），落地摊开，分裂 |
| `edge` | 高光线 |
| `decal` | 湿迹：暗、不规则边、慢干（寿命长） |
| `ground` | 水洼 + 涟漪 |
| `shock` | 涟漪环（多道、快衰） |
| `light` | 默认关 |

**2D / 3D 差异**：2D 液滴用 SDF 平滑并集 + 边高光线，3D 用网格 + 法线；2D 湿迹是地面线上的椭圆；表面场 2D 为一条起伏带。

### 3.10 奥术 `arcane`

**物理画像**

| 维度 | 倾向 |
|---|---|
| 运动 | 轨道、几何旋转、相位跳变（周期性瞬移到对称位）、悬浮 |
| 形态 | 符文 / 几何环 / 多面体框线 / 星图；精确对称、细线 |
| 边缘 | 硬细线 + 柔光晕（双阈值，比雷更规则） |
| 能量 | 中强发光，紫蓝 / 品红 / 青；相位脉冲（周期性） |
| 重力感 | 无（悬浮） |
| 残留 | 符文印记（几何，淡出）、悬浮光粒 |

**色板**：`primary` (0.5, 0.25, 1.0) · `secondary` (0.2, 0.8, 1.0) · `hot` (2.5, 1.8, 4.0) · `cool` (0.15, 0.05, 0.35) · `residue` (0.4, 0.3, 0.6)

**材质族预设**：噪声 = 低权重；主力是**程序化符文 / 几何 SDF**（`sdf_rune_ring` 生成：环 + 等分刻线 + 随机符号 SDF 组合，种子驱动）+ 旋转 + 分层反向旋转；阈值 = 细线硬 + 晕软；边缘 = 双阈值；流动 = 旋转 + 相位脉冲（周期 1~2 s 亮度峭点）；顶点位移 = 无或几何呼吸缩放；发光 = 中强。**3D**：多层同心环网格（不同轴倾斜旋转）；**2D**：多层同心环 quad（前后 Sorting）。

**GPU 粒子族预设**：主力场 = 轨道场（Orbital）+ 悬浮（无重力）+ 周期相位跳；基础形 = 小几何（菱 / 三角 / 符号 quad）+ 光点；寿命长；尺寸恒定；碰撞无；事件 = 相位脉冲时全部粒子亮度峭点。

**CPU 粒子族预设**：Velocity Orbital + Radial 0；Rotation 恒定；Color 周期脉冲（Color over Lifetime 用多峰渐变近似）；Size 恒定。

**几何族预设**：基础形 = 框线多面体（正八面体 / 二十面体线框，`wire_polyhedron` 生成器）与同心环；`link` = 直线 + 节点符号；`mesh_shell` 破裂 = 相位散解（几何碎成小多面体旋转飞散后瞬消）；`mesh_shell.cage` = 同心环 / 框线笼；`ground` = 符文阵（多环 + 刻线）；`orbit` = 框线多面体。

**局部光预设**：色温不适用，直接色 `primary`；强度倍率 1.0；模式 `pulse`（速率 0.7 Hz，深度 0.5，尖峰形）；衰减 = 尖峰后平滑。

**层角色注入表（显著项）**

| 角色 | 奥术的改写 |
|---|---|
| `core` | 框线多面体 / 符文球（旋转） |
| `body` | 同心环层（反向旋转） |
| `trail` | 悬浮几何碎片 + 细光线 |
| `emission.*` | 小几何符号轨道悬浮 |
| `ground` | 多环符文阵 |
| `link` | 直线 + 节点符号 |
| `orbit` | 框线多面体 |
| `mesh_shell.dissolve` | 相位散解 |
| `light` | 紫蓝、周期脉冲 |

**2D / 3D 差异**：2D 同心环用极坐标 SDF 在 quad 上直接绘制，倾斜环用椭圆 SDF；3D 用真实倾斜环网格。

**物理画像**

| 维度 | 倾向 |

**层角色注入表（显著项）**

| 角色 | 血的改写 |

## 4. 无元素 / 纯物理类 `none`（含 5 个物理子画像）

`element: none` 时不注入任何"能量性格"，层的外观由**物理子画像**（`physicalProfile`）决定；物理子画像仍是 ElementPreset 结构，只是 `light` 全关、色板取源材质或中性值。物理破坏类（D 类）原型默认使用本类。

| 子画像 id | 适用层角色 | 材质族 | 粒子族（GPU / CPU 通用倾向） | 几何族 | 色板 |
|---|---|---|---|---|---|
| `dust`（烟尘） | `emission.dust*` / `body`（尘云） / `emission.smoke` | 低频 FBM 大团、软阈值、低 alpha、缓慢上升或贴地扩散；无发光 | 大 quad、长寿命、起小变大、极慢、Noise 弱、贴地时 Y 速度 ≈ 0 | — | 灰褐 (0.45, 0.42, 0.38)，alpha 0.3 |
| `rubble`（碎石 / 碎块） | `debris*` / `emission.chips` | 源材质（用户网格）或中性岩石纹；断面 `edge.fracture` 为稍暗的同色 | 网格粒子（小不规则块）、强重力、弹跳滚动、停留、落地生尘 | Voronoi 块状破碎 + Rigidbody；`rock_chunk` 生成器 | 源材质 / 中性灰 (0.5, 0.48, 0.45) |
| `cloth`（布料） | `cloth` / `edge.fray` | 双面、布纹低频噪声、边缘磨损阈值；无发光 | 脱落线头（细拉伸 billboard、弱重力、强阻力） | Cloth 组件 / 顶点位移波；撕裂 = 约束断开或阈值挖空 | 源色 / 中性 |
| `liquid`（通用液体） | `core.crown` / `emission.drops` / `decal.wet` / `link.stream` / `ground.pool` | 与水元素材质族相同但无色（透明 + 高光），`viscosity` 中 | 与水相同 | 与水相同 | 透明 + 高光 (1.2, 1.2, 1.2) |
| `spark_metal`（金属火花） | `emission.sparks` / `flash.point` / `flash.tip` | 极短亮线、硬切；发光但**不带元素性格**（白黄短寿命，落地弹跳快熄） | 拉伸 billboard、重力、弹跳弹性 0.4、寿命 0.2~0.6 s、寿命末硬切 | — | 白黄 (3.0, 2.6, 1.8) 短 |

**与元素的边界**：`spark_metal` 与火元素的 `emission.sparks` 的区别是——金属火花是**碰撞产物**（近战 / 格挡 / 破碎的物理反馈，直线短促、快熄、无烟）；火元素火星是**燃烧产物**（上飘、湍流、寿命长、有烟）。同理 `dust` 与土元素 `body`（尘土云）的区别是土元素会把尘云染成土色板并加碎石，`dust` 只是中性灰尘。

**默认注入规则**：
- D 类原型在 `element: none` 时按层角色自动选子画像：`debris*→rubble`、`emission.dust*→dust`、`cloth→cloth`、液体相关层→`liquid`。
- 任何原型的 `emission.sparks / flash.tip / flash.point` 在 `element: none` 时→`spark_metal`。
- 其他层在 `element: none` 时使用**中性能量画像**：白 / 灰色板、无噪声形态倾向（原型层默认值）、`light` 关。这保证任何原型在无元素时也能编译出"结构可见"的中性预制体（画廊用它验收结构）。
