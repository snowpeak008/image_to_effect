# 参考图技术读解（质感基准）

日期：2026-09-05　|　来源：用户提供（`1.png` ~ `10.png`）　|　上位规范：`docs/rules/ADR-010_CONTENT_PARADIGM.md`

## 0. 这些图是什么、不是什么

**是**：商业水准的**质感标尺**。用于回答"我们的产物够不够商业化"这一个问题，判定方式是样片交付时的**截帧并排对比**（PlayMode 截帧能力已存在于 `Runtime/Diagnostics/W24ContinuousCaptureRecorder`）。

**不是**：

- 不是要复刻的目标特效。任何"照着 3.png 做一个火焰投射物"式的任务都属 ADR-010 §10 偏离。
- 不是样片清单。T2c 样片按跨大类跨元素原则另定，刻意避开"发光能量类"扎堆。
- 不是素材来源。图中所见形态一律程序化重建，不描摹、不切图、不做序列帧。

**用途**：从中提炼**可迁移的技术特征**，写入技术族实现规格，服务全部 58 个原型。

## 1. 逐组读解与技术映射

### A 组（`1.png`~`4.png`）火焰投射物

| 观察到的特征 | 技术映射（写入 T2b 规格） |
|---|---|
| 主体是**沿运动轴拉伸的丝带/条纹结构**，不是团块 | 噪声必须**各向异性**：沿运动方向低频、垂直方向高频；主体形态用条带网格（`sweep_band` 类生成器）而非单一 billboard |
| 亮度**四级陡分**：白热头 → 饱和橙 → 深红 → 暗红烟 | HDR 强度分层，不是简单色相渐变；色板需 primary/secondary/hot/residue 四段并在线性空间处理 |
| 头部后方大范围**低亮度红色雾幕**，宽度远超主体，透明度极低 | `veil` 层：大尺寸低 alpha 软噪声面，排序在主体之下 |
| 少量**离散亮火星**，数量少但强度高 | `emission.sparks`：低数量高亮度，与主体亮度分级拉开 |
| 头部边缘光晕溢出 | 自包含辉光层（加法柔光）+ 用户侧 Bloom 共同达成 |

### B 组（`5.png`~`7.png`）冰刺爆发

| 特征 | 技术映射 |
|---|---|
| 主体是**硬边晶体簇几何**（真网格），带内部渐变与边缘高光 | 几何族 `crystal_cluster` 生成器 + 菲涅尔边缘材质；硬边靠几何而非贴图 |
| **放射状光针阵列**：从中心向外的细长高亮射线 | **新增技术变体 `radial_spike_array`**（T2a 层词表未覆盖，T2b 补入）：程序化细长四边形阵列，长度/密度/随机角可调 |
| 硬体 + 柔光的**质感反差** | 晶体硬边界 + 外围柔光晕分层实现，是本组最关键的观感来源 |
| 底部接地辉光、周围漂浮碎片 | `ground` 层软光斑 + `debris` 低速粒子 |

### C 组（`8.png`~`10.png`）雷电爆炸

| 特征 | 技术映射 |
|---|---|
| **白热核心球**，中心过曝到纯白 | HDR 强度远超 1.0 的核心 + 辉光层 |
| **分叉电弧**，递归树状 | 几何族 `jagged_polyline` 递归分叉生成器（T2a 已覆盖） |
| **薄椭圆冲击环**，亮而细 | `wave_ring` 原型 + `ring_torus_segments` 生成器（T2a 已覆盖） |
| 冷蓝外围 / 纯白内核强反差 | 色板 hot 段与 cool 段拉大距离；局部光 strobe 闪烁模式 |

## 2. 跨组共性（对所有原型有效的质量准则）

1. **亮度必须分级而非渐变**：至少三到四个可辨识的强度台阶（白热核 / 主色 / 暗部 / 残留），这是"看起来有能量"的核心。
2. **硬与柔并存**：主体形态锐利（几何或高对比阈值）+ 外围柔光晕，反差产生质感。单一柔度的产物一定显得廉价。
3. **形态各向异性**：运动方向与垂直方向的噪声频率必须不同，否则回到"团块感"。
4. **低亮度大范围雾幕**：几乎每张参考里都有一层被忽略的低对比大范围衬底，它撑起体量感。
5. **离散高亮点极少但极亮**：火星/碎片数量克制，亮度顶格。
6. **光晕溢出**：自包含辉光层承担七八成，用户侧 Bloom 补足。

## 3. 辉光/后处理的边界裁定（用户 2026-09-05）

| 方式 | 归属 | 说明 |
|---|---|---|
| 特效自造光晕（加法混合柔光层，跟随特效自身） | **预制体内部，可自带** | 只影响特效自身占据的屏幕区域，不改变别人的画面 |
| URP Volume 全屏 Bloom | **归用户，预制体不含** | 作用于整屏，会改变用户画面调子与他人特效 |
| 画廊验收场景的 Bloom | 场景配置，非资产 | **做成可开关**：开=看完整成品观感，关=看资产裸质量 |

判据一句话：**光晕跟着特效走 = 可自带；光晕改变整个画面 = 归用户。**

## 4. 素材生成纪律（用户裁定）

具体贴图素材需求走**本地 codex CLI 现生成**，承担范围严格限定：渐变查找表（色板 LUT）、遮罩形状、噪声种子图。**不做主体形态、不做序列帧**（ADR-010 §5）。主体形态一律 shader 内程序化计算。
