# W24 machine gate report template

- effect ID / candidate ID / contract revision
- contract hash / build hash / capture profile hash
- exact machine verdict: `MACHINE_PASS` or `MACHINE_FAIL`
- requirement table: ID, type, authority, authority evidence reference+hash, independent cross evidence reference+hash, pass/fail
- Implementation Trace coverage: contract count, trace count, missing IDs, extra IDs
- known-cheat corpus: test ID, authority failed, cross-evidence alarmed
- cleanup, seed, budget and object-identity results
- non-visual conclusions only; never use “commercial quality” or L4
