# Cohort C preregistration

Cohort B is retained but **does not count**: its initial/repair chain was not immediately persisted and its repair reports were not generated by the actual API at the required time. No missing B artifact is reconstructed.

This directory is pre-registered before any C output. Each C agent gets the formal contract below plus exactly its fixed natural-language requirement, uses `gpt-5.6-terra`/`high`/`fork_turns:none`, and has no tools or workspace. Every returned response is written before running the evidence test; every repair prompt contains the unmodified report file written by that test.

Common contract, verbatim input: Return exactly one raw JSON Recipe object, no prose. Root fields are recipeVersion=1, revision=1, id, optional name, dimension="2d", archetype="projectile", optional style="stylized", targetProfile, randomSeed, stages, metadata with string createdBy/templateCatalogVersion. Buildable v1 requires stages launch/on_launch, travel/after_previous, impact/on_hit. Each stage has id, trigger, finite nonnegative duration, enabled, modules. Each module has id, kind, templateId, parameters, enabled, optional attachTo. Copy exact case-sensitive template IDs and pair them to these semantic kinds: PFT_2D_LaunchFlash/impact_flash(lifetime .06-.22,size .45-1.8); PFT_2D_FireCore/energy_body(scale .6-2.4); PFT_2D_FireTrail/motion_trail(time .08-.4,width .12-.55); PFT_2D_Embers/secondary_particles(rate4-36,lifetime .25-1.1); PFT_2D_FireImpact/impact_burst(count integer8-40,speed1.5-6); PFT_2D_Shockwave/shockwave(lifetime .12-.5,endSize1.2-4). Do not use unknown fields; all declared parameters must be present.

Fixed requirements: C1 a bright quick PC 2D comet with light embers; C2 a heavy mobile 2D bolt with broad trail; C3 a tiny PC spark with no trail and a compact impact; C4 a mobile ribbon with narrow trail and no embers; C5 a PC nova with normal travel and emphatic impact.
