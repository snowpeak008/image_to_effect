# Cohort G preregistered natural-language prompts

These prompts were registered before any Cohort G model output. Each Recipe author receives the frozen contract snapshot and only its own prompt; the acceptance specification is not supplied.

## G1

Create a complete buildable 2D projectile Recipe with ID `g1_cinder` for `mobile_medium`: a compact cinder with a smaller core, narrower trail, fewer embers, and a restrained impact.

## G2

Create a complete buildable 2D projectile Recipe with ID `g2_lantern` for `pc_editor`: a large lingering lantern-like fireball with a larger core, longer trail, longer-lived embers, and a larger shockwave.

## G3

Create a complete buildable 2D projectile Recipe with ID `g3_needle` for `mobile_medium`: a small precise needle of fire. It must omit optional trail and ember modules, retain a smaller body, and use a restrained impact.

## G4

Create a complete buildable 2D projectile Recipe with ID `g4_whisper` for `pc_editor`: a quiet thin orb with a narrow trail, no ember module, a slower impact burst, and no larger shockwave.

## G5

Create a complete buildable 2D projectile Recipe with ID `g5_flare` for `mobile_medium`: a bright strong flare with at least the standard core and ember intensity, a stronger impact burst, and a larger shockwave.

## P1

Return a Patch only that reduces the canonical travel embers emission rate to 9.

## P2

Return a Patch only that disables the canonical travel embers module.

## P3

Return a Patch only that adds a second ember module named `lighter_embers` to canonical travel, attached to `core`.
