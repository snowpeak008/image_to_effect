# Cohort H — invalid and noncountable

H1 was interrupted immediately after a manually transcribed initial spawn was discovered not to byte-match its frozen payload. No H model output, attempt, report, transport witness, Recipe asset, history, or Generated asset was persisted. The interrupted transport is invalid; **Cohort H is noncountable and must never be used for M6 scoring**. Its preregistration files remain preserved for audit only. Cohort I supersedes it with a file-backed short-envelope transport.

H is the only new proposed countable S9 cohort. It contains exactly Recipe questions `H1`–`H5` (threshold: at least 4/5 successful) and Patch questions `P1`–`P3`. All question text, semantic assertions, transport routes, and evidence filenames are frozen before any H output exists.

Each key has one isolated `gpt-5.6-terra` / `high` / `fork_turns:none` agent. Its complete initial message is the frozen formal contract snapshot followed by exactly one preregistered requirement. A failed key keeps that same agent/thread for at most two `followup_task` repairs. The repair payload is written once before it is sent, has an SHA-256 record, and contains the fixed instruction plus the complete previous machine report after LF-only normalization. It deliberately does not retransmit, compress, or rewrite the contract, original requirement, or previous output, because that same thread retains them.

The platform does not expose a wire-payload readback. Therefore H provides local canonical-payload evidence plus a human-visible collaboration record: before every repair, the developer pauses and reports the target agent name, prepared-prompt path, and hash to the primary Agent; the primary Agent reads that file, verifies it, and personally calls `followup_task`. This is not an end-to-end machine proof of the transmitted bytes and must be disclosed in the final report. A transport witness records the asserted same-thread ID and matching local payload hash after dispatch; it is not represented as wire capture.

Before approval, H must have a verified one-time contract snapshot, generated initial payloads, and no attempt, report, final, repair, or actual transport evidence. No H model may be dispatched before the primary Agent explicitly approves.
