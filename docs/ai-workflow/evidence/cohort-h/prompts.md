# Cohort H preregistered natural-language prompts

These new requirements are fixed before dispatch. A Recipe agent receives its frozen contract snapshot and only its own requirement; a Patch agent receives the same snapshot and only its own Patch requirement.

Create a complete buildable 2D projectile Recipe with ID `h1_cinder_shower` for `pc_editor`: a small bare fire mote with no optional trail, a dense but short-lived ember shower, a forceful impact burst, and a restrained shockwave ring.

## H2

## H3

## H4

## H5

Create a complete buildable 2D projectile Recipe with ID `h5_forge_hammer` for `pc_editor`: a large heavy orb with a broad but short trail and no ember module; use a lower-speed forceful impact burst and a large shockwave ring.

## P2

## P3
