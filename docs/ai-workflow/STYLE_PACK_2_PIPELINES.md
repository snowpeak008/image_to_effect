# Style Pack 2（W16）

新增 token：`lowpoly / crystal / candy / cosmic / steampunk / ghost`。

| token | 机器协议 | 共享构件 |
|---|---|---|
| lowpoly | `flat_shading=true`、`facet_mesh` | Facet Mesh A/B/C |
| crystal | `dispersion_strength` | Facet Mesh + Holo/Fresnel shader |
| candy | `squash_curve` | Symbol Atlas |
| cosmic | `nebula_noise` | Nebula A/B + Star Atlas |
| steampunk | `step_fps`，Runtime 棘轮式时间量化 | Gear Mesh A/B/C |
| ghost | `ghost_pulse_fps`，受控透明呼吸 | SoftNoise shader |
