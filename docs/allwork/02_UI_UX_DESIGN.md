# W2 VFX Studio 编辑器界面（UI/UX 完整设计）

> 实施状态（2026-08-24）：五页签 EditorWindow、数据层、确认式写入与 Review 签署保护完成；界面视觉/易用性验收按总计划延后，由用户统一签署。实现与证据见 `docs/stage-notes/W1_W2_STYLE_STUDIO_REPORT.md`。

> 目标：把现在唯一的 141 行 `VfxCompilerWindow` 升级为一个完整的 **VFX Studio** EditorWindow，覆盖"浏览 → 生成 → 预览 → 修改 → 验收"全流程。所有操作仍走既有编译器/Patch 事务，UI 不引入新的资产写入路径。
> 技术基线：Unity IMGUI 或 UIToolkit（推荐 UIToolkit，2022.3 成熟）；程序集 `VFXComposer.Editor.UI`；只依赖 Editor 程序集，不产生 Runtime 反向依赖。

---

## 1. 信息架构

菜单入口：`Tools/VFX Composer/Studio`（保留旧 Compiler 窗口为兼容入口）。

主窗口五个页签：

```
┌────────────────────────────────────────────────────────────────┐
│ [库 Library] [生成 Create] [预览 Preview] [修改 Patch] [验收 Review] │
├──────────────┬─────────────────────────────────────────────────┤
│              │                                                 │
│  左栏：导航/  │        主区：当前页签内容                          │
│  过滤/列表    │                                                 │
│              │                                                 │
├──────────────┴─────────────────────────────────────────────────┤
│ 状态栏：当前 Recipe · 模板版本 · build hash · 预算灯 · 最近错误      │
└────────────────────────────────────────────────────────────────┘
```

---

## 2. 页签一：库 Library（特效库浏览）

**目的**：让 90+ 特效族与其风格变体可发现、可比较、可一键进入预览。

- 左栏三级过滤器（复选，可组合）：**Archetype**（Projectile/Impact/Slash/Aura/Area/Beam/Trail/Shield/Spawn/Transform/Composite/Environment/Screen）、**维度**（2D/3D）、**元素**（火/冰/雷/水/风/土/自然/毒/圣/暗/奥/中性）、**风格**（8 个 token）。顶部搜索框按 id 与中文别名模糊匹配。
- 主区卡片网格：每卡显示缩略图（取该特效验收证据里的峰值帧 PNG，无则显示占位）、id、Archetype 徽章、维度徽章、风格色点、预算灯（绿=达标 / 黄=接近上限）。
- 卡片操作：双击 → 跳到 Preview 页签并加载；右键 → 定位 Recipe / 定位 Prefab / 复制 id / 以此为基新建变体（跳 Create 页签预填）。
- 数据来源：扫描 `Recipes/**/*.json` + Generated Manifest，不新建索引资产；缩略图路径按验收证据目录约定解析。

## 3. 页签二：生成 Create（文字/图片 → Recipe）

**目的**：把现有"手写 JSON → 命令行编译"流程变成向导。**AI 只产 JSON，UI 只做校验与展示**，与既有安全边界一致。

三步向导：

1. **输入**：左侧自然语言描述框 + 可选参考图拖入区（参考图仅存证据目录记录来源，绝不直接进特效，沿用 S14/S15 规则）；右侧选择 Archetype、维度、风格 token、目标模板（下拉列出 Manifest 已登记模板，附参数说明，数据来自 `template-parameters.generated.md` 的生成源）。
2. **Recipe 草稿**：中央 JSON 编辑器（只读结构树 + 可编辑参数表单双视图）。"从描述生成"按钮把 Prompt+模板参数说明复制到剪贴板/写入交换文件，用户经 Codex 等外部工具产出 JSON 后粘回；粘回即时 Schema 校验，错误逐条列出并可点击定位字段。
3. **编译**：显示 Dry-Run 结果（将写入的路径、预算预检、模板版本），确认后走正式编译事务；成功后自动跳 Preview。

## 4. 页签三：预览 Preview

**目的**：统一的所见即所得预览，替代散落的各 Preview 场景入口，但**复用**既有唯一审查相机与真实 PlayMode 播放原则。

- 主区嵌入预览视口（打开对应 Preview Scene 的相机画面）；下方传输条：播放 / 暂停 / 单帧步进 / 0.25×–1× 速度 / 循环开关；one-shot 自动重播间隔可调。
- 关键帧书签：按该特效规格卡的 Phase 时间线自动打点（如 `.033/.10/.166/.233/.333/.45`），点击跳到该时刻附近暂停，供逐帧对照验收表。
- 右栏实时只读指标：当前粒子数/峰值、透明 Renderer 数、材质数、预算限额对比（红黄绿）；数据走现有静态预算与粒子 readback 通道，不调用 `Camera.Render` 抓帧。
- 工具按钮：斜视角/正视角切换（仅 3D，切换到规格声明的第二审查机位）、同屏 A/B（加载另一风格变体并排播放）、导出证据帧（调用现有 authority 录制路径，输出到该特效 evidence 目录）。

## 5. 页签四：修改 Patch

**目的**：把"火星减少一半"式局部修改做成界面操作。

- 左栏：当前 Recipe 的模块树（按视觉五职责分组：主体/高光/外部能量/次级粒子/消散）。
- 主区参数表：选中模块后列出 Manifest 声明的可调语义参数，滑杆/色板编辑；每次改动生成一条**待应用 Patch**（右侧 Patch 队列可见、可撤销排队项），不直接改资产。
- 「应用」走既有 Patch 事务：校验 → 局部重建 → 预览自动刷新；失败回滚并显示错误码。
- 「导出 Patch JSON」把队列存为 `Recipes/Patches/<id>.<描述>.patch.json`，作为文字驱动修改的示例资产。
- 风格快捷区：风格 token 下拉（触发 `set_style_token`）+ 三色色板（触发 `set_palette`）。

## 6. 页签五：验收 Review

**目的**：把 DoD 检查从纯命令行搬进界面，形成"验收清单即界面"。

- 检查项列表（自动执行按钮 + 状态灯）：Schema 校验 / 构建幂等复检 / 静态预算 / one-shot 清空检测 / sustained 三周期稳定 / Stop-Reset 干净 / 证据帧齐全。
- 人工项复选框（形状、层级、动作、消散、深度感），勾选人 + 时间写入该特效 evidence 目录的 `REVIEW.md`；全绿 + 人工全勾 → 状态标记"已验收"，Library 卡片显示 ✅。
- 批次视图：选择一个批次（allwork 文档编号），显示该批次全部特效的验收矩阵总览。

## 7. 交互细节与视觉规范

- 全窗口操作**绝不**静默写资产：任何写入前显示 Dry-Run 路径清单；删除/覆盖一律确认框。
- 错误显示统一格式：错误码 + 人话说明 + 「定位」按钮（选中出错字段/文件），与 `ERROR_CODES.md` 双向一致。
- 长操作（编译、录帧）走进度条 + 可取消；操作日志落 `Logs/vfxstudio.log`。
- 深色主题适配 Unity Pro skin；最小窗口 1100×650；左栏可折叠。

## 8. 分期交付

| 轮次 | 内容 | 验收 |
|---|---|---|
| UI-1 | Library + Preview（只读链路） | 能浏览全部现有特效并播放、打书签、看预算灯 |
| UI-2 | Create 向导 + 编译接入 | 从模板+表单产出新 Recipe 并编译成功 |
| UI-3 | Patch 页签 | 界面完成一次"火星减半"并可导出 Patch JSON |
| UI-4 | Review 页签 + 批次矩阵 | 一个批次的 DoD 全部在界面内完成 |

每轮 DoD 附加：EditMode 测试覆盖窗口数据层（过滤、校验、Patch 队列序列化），UI 逻辑与数据层分离以便测试。
