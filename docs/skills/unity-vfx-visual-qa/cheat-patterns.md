# Captured-image cheat patterns

Search the filmstrip and stated evidence locations for these observable patterns. Report the relevant contractual requirement; do not infer an internal cause from pixels alone.

| Pattern | Image-level signal to record | Authority boundary |
|---|---|---|
| whole-image/mesh rotation posing as fragments | multiple supposed fragments retain one rigid rotation/relative arrangement over the inspected interval | telemetry is authoritative for independent instances |
| full-flame image or static ribbon posing as sustained burn | the same complete silhouette rotates/repeats without stated variation, or persists past stop deadline | telemetry/diagnostic own sustained-state and cleanup facts |
| static line posing as trail | trail occupies a fixed path while the emitter position changes, or grows into new space while emitter is stationary | telemetry owns vertex origin |
| detached model effect | declared attached layer remains visibly offset from the designated anchor during model motion | telemetry owns actual binding |
| additive brightness posing as light | brightness change is confined to the effect body while the declared receiver area shows no stated change | diagnostic owns receiver luminance |
| hard stage switch | a contractually continuous anchor/residue disappears in one transition without an allowed continuity mode | contract and diagnostic determine formal continuity |
| obstruction or hierarchy inversion | a required subject is occluded by a named layer at the required frame/ROI | visual-semantic QA if the contract states the relationship |

Add a newly observed pattern only after the user or a reviewed rejection establishes it. Then update the contract rule, machine gate where applicable, frozen known-cheat corpus, and Human Verdict Corpus together.
