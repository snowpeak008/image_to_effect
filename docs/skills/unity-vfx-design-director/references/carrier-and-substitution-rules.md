# Carriers and prohibited substitutions

Select a carrier deliberately per layer. Record the selected carrier and the denied substitute in the contract.

| Intended fact | Required implementation fact | Disallowed shortcut |
|---|---|---|
| independent fragments | independent transforms or particle instances with distinct movement | one rotating mesh or image |
| sustained burning | a time-varying sustained effect and stop cleanup | rotating full-flame image or static ribbon |
| projectile trail | geometry generated by real emitter movement | fixed decorative line |
| model attachment | tested Transform, Socket, Mesh, or bone binding | nearby independent primitive |
| scene lighting | Light/Light2D plus receiver luminance evidence | additive brightness alone |
| staged effect | specified continuity anchor, residue, direction, or energy transition | unrelated layers alpha-switched by time |

If the required carrier is unavailable, return `UNSUPPORTED_CARRIER` or explicitly design a lower L2 placeholder. Never call it equivalent.
