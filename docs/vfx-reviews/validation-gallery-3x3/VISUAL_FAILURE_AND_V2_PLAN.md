# 九宫格五类新特效视觉失败与 V2 重建计划

日期：2026-08-23  
状态：V1 视觉拒绝；V2 候选已完成工程验证，等待用户视觉验收

## 1. 失败结论

V1 的工程结构和生命周期成立，但视觉不合格。直接原因是把“零 PNG、三层 Quad、共用单一数学遮罩”当成主目标，导致 Aura、Beam、Trail、Shield、Spawn 只有类型符号，没有游戏特效所需的能量层级、动作阶段和材质细节。`IsAlive`、前景像素和清空测试只能证明可运行，不能证明质量。

V1 不得作为五类新特效的视觉基线，只保留为失败证据。现有 Projectile、Impact、Slash、Area 仍是九宫格中的独立对照项。

## 2. V2 共同标准

- 每类至少具备主体、内部高光、外部能量、次级粒子、消散五种视觉职责；不得只是一个圆环或一条线。
- 每个 Runtime Entry 保持独立 Prefab、单根控制器、Idle Renderer 关闭、自然 Update、Stop/Pool 清理。
- 允许 `5` 个程序化 Renderer 加 `1` 个真实 ParticleSystem；简单类总 GameObject 不超过 `10`。
- 不新增每效果独占大图。优先共享 Shader、Quad、Material；本轮保持新增 PNG 为 `0 B`。
- Shared 不等于免费：报告 Prefab 源码、Shared 源码与递归依赖；不把 YAML 大小冒充 Player Build。
- 九宫格主帧必须九格同时可见并逐 Cell 计数；人工检查造型差异、层级、动作、重复感和裁切。

## 3. 五类冻结目标

### Aura

双层不规则能量场、旋转断续符文、内部流动纹样、轨道光点和受事件驱动的扩散脉冲。禁止只剩“圆盘 + 十二方块”。

### Beam

宽软辉光、连续高亮主电弧、至少两条可辨分支、两端能量节点和沿路径游离的电火花。禁止单条等宽折线。

### Trail

具有方向的锐利彗核、双层收束拖尾、横向摆动、尾部碎光和逐步消失的离散粒点。主体不得是椭圆加一排圆点。

### Shield

透明护盾面、双层六边形边框、可读的内部六边结构、沿边能量流和命中扩散波。禁止只有空心六边形。

### Spawn

内外双法阵、旋转弧段、非均匀符文、中心涡流、上升能量粒子和完成闪光。禁止花瓣圆环式静态图标。

## 4. 验收边界

V2 必须先通过同一保存场景、同一 Main Camera、自然 Update 的 60fps 证据，再由主 Agent 逐帧审图；最终状态仍为 `pending user visual acceptance`，直到用户在 Unity Game View 中确认。
